# TEST-3 — serialized synthetic slab reference

Status: implementation, independent review and full verification complete.
Baseline: merged main `4db45c4`. Work branch: `fix/test-3-synthetic-slab`.

## Purpose and scope

`tests/synthetic_slab.py` generates a reusable 16-atom, six-frame `pp pp ff`
reference. `tests/test_slab_reference.py` exercises serialized parsing, shell
metadata/load order, cached/shared processing and numerical/plotting consumers
against independent analytic expectations. Existing unit cases already cover
many individual slab paths; this item adds a common end-to-end reference.

**Runtime generation is deliberate:** rather than committing or editing numeric
files under the frozen `tests/fixtures/**`, the committed generator writes its
dump and metadata into temporary directories. This implements the functional
TEST-3 reference requirement without changing the established fixture/golden
baseline. It differs from the old suggestion of committing a dump alongside its
generator; both reproducibility and the generated bytes are tested explicitly.

This is a toy geometry, not an equilibrated Fe lattice, real LAMMPS dynamics,
chemical dissociation/uptake kinetics or a diffusion measurement. Distance-one
pairs are geometric cutoff probes, not a validated O2 bond length. ID 108's
alternating 39-Angstrom z jump is intentionally nonphysical. It makes incorrect
periodic z folding unmistakable. This is **not GEN-8**: the second non-Fe physical
reference still requires the maintainer's choice.

## Fixed case definition

- Box: `[0,20] x [0,20] x [0,40]` Angstrom; x/y periodic, z nonperiodic.
- Six saved steps: 0, 10, 20, 30, 40, 50; explicit metal timestep `.001 ps = 1 fs`.
- Eight fixed substrate atoms: the Cartesian product x/y/z = `{4,8}` Angstrom.
- O IDs 101/102 form a distance-one pair straddling x at the initial frame;
  both translate `0.4*k` Angstrom. IDs 103/104 do the same in y with `0.3*k`.
- IDs 105/106 are at the same x/y but z = `.2` / `39.8` Angstrom. Their actual
  slab separation is `39.6`, not a false periodic `.4` Angstrom neighbor.
- ID 107 descends from z = 12 to 2 in increments of -2 Angstrom.
- ID 108 alternates z = `.4` / `39.4`, while remaining far laterally from others.
- IDs stay fixed but row order is deterministically permuted in every frame.
- A manual analysis plane at z = 8 defines OAR/summary penetration. Separately,
  the profile's 95th substrate percentile is also 8 in this particular geometry.

The companion input contains metadata only (`units metal`, `boundary p p f`,
`pair_style zero 3.0`, `timestep .001`); it is not a runnable production input.
Dump element labels are explicit. Force-field names/spin outputs are not test
oracles: legacy dump heuristics remain visibly warned and are the separate
GEN-2 roadmap item. No real force field is being claimed by this reference.

## Independent expected values

Let k = 0..5 and use a strict below-surface comparison.

| Quantity | Analytic answer |
| --- | --- |
| time (ps) | `[0, .01, .02, .03, .04, .05]` |
| fixed substrate MSD | zero |
| O MSD (Angstrom^2) | `(4.5*k^2 + 1521*(k mod 2))/8` |
| geometric O2 pairs | 2 in every frame: 101–102 and 103–104 |
| unpaired O | 4 in every frame; bound/unpaired fractions both .5 |
| OAR absorbed count | `[2,1,2,2,3,2]`, divided by 8 for the fraction |
| deeper penetration, z < 5 | `[2,1,2,1,3,2]` |
| near-surface band, 5 <= z < 11 | `[0,1,1,1,0,0]` |
| minimum O z | `.2` in every frame |
| profile first observed below surface (ps) | `[0,0,.03]` |
| initial-cohort uptake | only 3/8 ever below; no t50 annotation |

For O–O RDF with radius 3 and eight bins, exactly four ordered pair
contributions at r = 1 occupy zero-based bin 2 (`[.75,1.125)`). Box volume is
16000 and N is eight, giving

`g[2] = 1000 / ((4*pi/3) * (1.125^3 - .75^3))`, all other bins zero.

The oracle enumerates **nine** x/y image translations with zero z shift, finds
one minimum image per physical unordered pair, and counts both directions only
for RDF normalization. It does not call production MIC or candidate helpers.
The shell's default radius/bins differ from the eight-bin API case, so its
curve is checked against a separate enumeration on its actual default grid.

A deliberately different fully periodic interpretation gives three geometric
pairs and O MSD `(4.5*k^2 + (k mod 2))/8`. These contrasting controls establish
sensitivity to the boundary flag; they are not the correct slab answers.

## Reproduce without touching tracked fixtures

```bash
WORK="$(mktemp -d)"
python tests/synthetic_slab.py "$WORK"
cat > "$WORK/check.commands" <<EOF
load input "$WORK/slab.in"
load dump "$WORK/slab.dump" --cache-mb 0
set surface_z 8
analyze all
analyze msd --species O
analyze rdf O-O --frames 6
export summary "$WORK/summary.txt"
EOF
HOME="$(mktemp -d)" LKPR_NO_HISTORY=1 python -m lammpkeeper post \
  --batch "$WORK/check.commands" --output "$WORK/output"
```

The collected module is registered in `tests/run.py` and is also pytest
discoverable. Targeted execution uses that runner with `MODULES` restricted to
`test_slab_reference`; full verification executes it with all prior checks.

## Coverage and limits

- Generator bytes are deterministic across directories; its real CLI is also
  exercised using Python `-S` to prove no optional package dependency.
- Real native calls and NumPy parsing agree through streaming, indexed,
  cached and uncached access. Native absence/disablement explicitly skips that
  comparison rather than counting fallback as native success.
- The RDF test observes actual SciPy nominations before comparing forced
  fallback. Eight O atoms do **not** exercise the >20 accelerated O2 pairing
  branch; existing O2 tests retain that coverage.
- Both input/dump load orders and 0/4 MiB frame caches are exercised. The test
  wraps the real shared executor and asserts that it runs for zero-cache mode;
  this is not merely a set of sequential API calls.
- Real batch dispatch handles spaced paths and exports current metadata/results.
- Optional actual rendering saves/checks eight PNGs, inspects RDF/MSD artist
  data and verifies no false t50 annotation. No fake axes substitute for rendering.
- No production source, generated simulation/job input, existing fixture, golden,
  mapping convention, architecture or HPC site is changed. No LAMMPS/HPC runs,
  potential evaluation or equilibrium/kinetics claim is part of TEST-3.

## Review and verification

Targeted rich-environment execution (measured), including review follow-ups:
**10 passed, 0 failed, 0 skipped**. Independent read-only design review agreed
with the analytic expectations. Final implementation review identified two
false-pass risks that were corrected before publication:

- Native parity now checks the compiled row count and forbids `np.loadtxt`
  during native reads. A successful native call cannot quietly certify fallback.
- Plot tests require all three artist-inspection branches and exact output
  filenames, and inspect cumulative uptake y-data `[1,2,3]` as well as times.

In-process fault injection (measured, no file changes) confirms that forcing
periodic z makes the slab MSD regression fail, and returning a wrong native row
count cannot hide behind NumPy fallback. These are validation checks, not extra
claimed physical trajectories or additional collected passing tests.
