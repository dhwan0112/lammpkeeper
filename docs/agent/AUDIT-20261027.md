## Physical and compatibility decisions

- RDF averages frame-normalized curves equally: each frame contributes its own
  histogram divided by `N_a * N_b / V` and spherical shell volume. This removes
  frame-order dependence. Same-species counting includes both pair directions;
  there is no second division by two. The finite-population ideal-gas plateau
  under this density convention is `(N-1)/N`.
- Triclinic analysis is not implemented in this repair. Readers reject tilt and
  changing trajectory boundary flags instead of discarding metadata. A future
  accepted box-model implementation may extend support without silent fallback.
- The current prep writer emits rectangular boxes. Odd-ny Fe(110)/(111) builds
  are refused. Supported even-width structures are checked by independent
  periodic-image nearest distances, not just file hashes.
- Zero fixed/NVT layer counts are explicitly unsupported, and negative counts
  are invalid. Supporting zero requires a separate disjoint region/fix design.
- O2 axes use uniform solid angle. Seeded coordinates intentionally differ from
  the biased historical distribution. This establishes isotropic initialization,
  not persistence through equilibration or a measured kinetics effect.
- Magnetite uses origin-choice-2 8a/16d/32e motifs plus FCC translations. Tests
  independently require 24 Fe/32 O, eight four-coordinate tetrahedral Fe and
  sixteen six-coordinate octahedral Fe. A separate ASE #227 setting-2 comparison
  matches all 56 element/fractional-coordinate pairs.
- Slab pressure rescaling requires an explicit per-sample `lz` and positive
  chosen slab thickness. It assumes the slab occupies the full box cross-section
  and all relevant box stress is assigned to it. It is not a local material
  pressure or surface-stress estimator. Missing geometry is visibly uncorrected.
- ID-union penetration plots retain missing samples as NaN gaps. Uptake t50 uses
  the initial cohort; later arrivals cannot establish that cohort's 50% uptake.
